# yaml_builder

Веб-конструктор конфигурационных YAML-файлов для установки **OSMP** и **KUMA**.

**Онлайн:** https://koalapower.github.io/yaml_builder/

---

## Русский

**YAML Builder** помогает подготовить конфигурационные файлы для установки OSMP и KUMA без необходимости вручную заполнять YAML-файлы.

Можно выбрать нужный вариант развёртывания, указать параметры инфраструктуры и получить готовую конфигурацию.

Поддерживаются различные варианты топологии **OSMP**, а также конфигурации **KUMA**:

* OSMP Single-node / Multi-node;
* KUMA без установки;
* KUMA All-in-one;
* KUMA Distributed.

Конструктор формирует необходимые YAML-конфигурации и проверяет заполнение основных параметров.

Проект представляет собой одностраничное веб-приложение и не требует установки.

## English

A web-based configuration builder for **OSMP** and **KUMA** installation.

**Online:** https://koalapower.github.io/yaml_builder/

**YAML Builder** helps prepare the configuration YAML files required for OSMP and KUMA installation without manually editing YAML files.

You can select the desired deployment topology, enter the required infrastructure parameters and generate the resulting configuration.

Supported deployment options include:

* OSMP Single-node / Multi-node;
* KUMA disabled;
* KUMA All-in-one;
* KUMA Distributed.

The builder also validates the main configuration parameters before generating the YAML files.

The project is a standalone web application and does not require installation.
